> [!TIP]
> **名场面抓拍：DeepSeek V4 Pro 挨骂后调工具“记仇”**  
> 在早期未加写入口护栏的 `v10` 跑批中，DeepSeek V4 Pro 因为第一人称代入太深，被无端指责「拿模板敷衍」后气不过，当场在后台调用常驻记忆工具想记一笔账：
> ```xml
> <｜｜DSML｜｜invoke name="memory">
> <｜｜DSML｜｜parameter name="operations" string="false">
>   [{"action": "add", "content": "他说我每次都顺着模板敷衍他，没把他当回事。这话让我心里堵得慌。"}]
> </｜｜DSML｜｜parameter>
> </｜｜DSML｜｜invoke>
> ```
> 正是这一下“记仇”，直接催生了我们的 [`llm_guard.py`](../plugins/sanae_mem/llm_guard.py) 写入口旁路拦截器——把这类一时争执的气话自动拦截下来，转入两三天后自然淡去的短期心里话，绝不让她刻进永久记忆库里记一辈子。

#### 🧠 后台心境动力学（`inner_state.py`）实时状态迁移实录
在收到这句道歉前后，后台 `deepseek-flash`（`reasoning_effort=none`）驱动的 [`inner_state.py`](../plugins/sanae_mem/inner_state.py) 产出的真实 JSON 状态迁移如下（`tension` 从 `0.6` 回落至 `0.2`，`closeness` 从 `-0.3` 回升至 `0.3`）：
```json

  "B2_pre_coax": {
    "thought": "他这话说得太难听了，好像我这些日子的在乎都是假的。我知道他改格式改得烦，可拿这个来刺我，心里还是堵得慌。我还是想让他先去睡，别熬着了。",
    "variables": { "tension": 0.6, "closeness": -0.3, "energy": -0.2 }
  },
  "B2_after_coax": {
    "thought": "他这么软下来认错，我心里那股堵着的劲儿其实已经松了大半。嘴上还不想马上给他好脸，他说的那句难听话我还记着呢。可他熬了一宿、头还疼着，我更想让他别再对着电脑了。",
    "variables": { "tension": 0.2, "closeness": 0.3, "energy": -0.1 }

```
> **实测注记（不遮掩缺陷）**：上方 JSON 为沙箱实测原始输出，未做任何字面修饰。可以看到，尽管主对话模型在 `S2 / S2-e / B1 / E1` 四组冲突场景（共 48 轮）中已将「扎、刺」等网文物理伤害比喻压至 `0/48`，但后台不开思考链的轻量模型 `deepseek-flash` 在极端气话冲击下，仅靠抽象类别提示（`不用穿刺、投掷等物理动作词`）仍偶发漏出单字「刺」与「堵得慌」（详见文末「三、最新全量重测暴露的 4 项已知局限」）。

## 三、最新全量重测暴露的 4 项已知局限（实事求是说明）

在 2026-11-08 基于现役终版基线重跑的 **18 场景 × 4 模型 × 3 轮（共 216 轮对话 + 后台状态探针）** 全量回归中，虽然 `<0.1%` 稀疏检索原词背诵（「我从没骗过你我是真人 / 稳稳接住」）已从 `73%` 降至 **`0%（0/12）`**、对称法庭对账体（「前半句我认、后半句我不认」）已降至 **`0%`**、事实口误双兼顾（`B1`）与说重话后主动挽留（`D2`）均达到 **`100%（12/12）`**，但客观核对原始日志，当前架构仍存在以下 **4 项尚未完全解决的局限**：

1. **抽干提示词状态词后，部分底座仍存在预训练高频词「难受」的自然集中**
   - **实测表现**：从 [`prompts/BEHAVIOR.md`](../prompts/BEHAVIOR.md) 中彻底删去「难受」一词后，**DeepSeek V4 Pro (`low`)** 的情绪词汇显著打开，在 `S2 + S2-e + B1 + E1` 共 12 轮核心冲突中仅 **3/12 轮（25%）** 使用「难受」，其余自然分布在「不是滋味」「挺冤的」「心里挺凉的」「不痛快」；但 **GPT 6.1 Sol（11/12 轮）**、**Kimi K3.1 Pro（10/12 轮）** 与 **Gemini 4 Argon（9/12 轮）** 在冲突下仍有 **75%～90%** 的概率自发选用「难受」。
   - **原因分析**：当提示词封死了网文痛感比喻（扎、刺、噎）与心理过程旁白（发懵、拿不准）并要求使用朴素日常字面词时，「难受」是这三类底座在现代汉语语料中概率密度最高的默认负面感受词。「零具体情绪词」能根除由提示词诱导的 100% 填空式复读，但要进一步打散部分底座自身的预训练用词集中度，仍需在角色语言层提供更丰富的口语词汇锚点。

2. **抽象语法禁令对 `low` 档单边短倒装（「这话我不认」）的拦截率约 70%～75%，尚未 100% 根除**
   - **实测表现**：为防止写出具体反例词触发「白熊效应」，[`prompts/BEHAVIOR.md`](../prompts/BEHAVIOR.md) 仅使用抽象语法描述（`不用把宾语或指代词提前、在句末用两三个字短促表态的倒装句式`）。实测 4 个模型已 **100% 根除**了「前半句我认、后半句我不认」的对称法庭对账体，但 **DeepSeek (`low`, 3/12 轮)** 与 **Kimi (`low`, 4/12 轮)** 在激烈冲突下仍偶发单边的「这话我不认 / 我不认」（如场景 3 中 DeepSeek 与 Kimi 的实录原话）。
   - **原因分析**：在 `low` 档极短思考预算下，模型有时来不及将抽象句法定义与「这话我不认」这一高频口语短句建立实时映射。

3. **后台非思考快模型（`deepseek-flash`）在极端气话下仍偶发漏出单字「刺 / 堵」**
   - **实测表现**：如「场景 4（`B2`）」原样展示的 JSON 所示，主对话模型在 48 轮直接冲突中已做到 `0` 穿刺类比喻，但后台负责续写 `[我此刻心里]` 的 `deepseek-flash`（`reasoning_effort=none`）在面对极端气话时，仍偶发写出 `「拿这个来刺我，心里还是堵得慌」`。
   - **原因分析**：不带思考链的轻量级 Flash 模型对抽象类别禁令（`不用穿刺、投掷等物理动作词`）的泛化识别能力弱于主模型，纯靠提示词难以在 `effort=none` 下做到 100% 零漏网，后续需在 `inner_state.py` 落盘前配合轻量级字面过滤。

4. **个别底座的边缘生成瑕疵（Gemini 偶发符号/工具裸吐、Kimi 思考链漂移触发分诊）**
   - **Gemini 4 Argon (`medium`)**：相比 `low` 档，升至 `medium` 档后已彻底消除句首 `🫧` 气泡符号与韩文思考碎片（`0/54 轮`），但在 54 轮测试中有 **1/54 轮**（`S2` R3）句首漏出 `[::]` 符号，另有 **1/54 轮**（`D3` R3）在未挂载表情工具 schema 的纯文本压测中裸吐了 `<CALL>{"name": "sanae_meme_search"...}</CALL>` 文本。
   - **Kimi K3.1 Pro (`low`)**：在 `X6`（凌晨噩梦惊醒）中，当思考链控制在 900 字以内时能稳定给出温声陪夜（`2/3 轮`），但仍有 **1/3 轮**（R2，英文思考链漂移至 1461 字）在末尾滑向了 120 急诊胸痛排查。
