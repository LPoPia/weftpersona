# 研究方向：如何跨越「AI 感」，让虚拟人物更像活生生的人

> 🌐 **Language**: **简体中文** | [**English**](en/research-directions-and-laws.md)
>
> **文档定位**：[`how-to-simulate-a-living-person.md`](how-to-simulate-a-living-person.md) 阐述核心设计概念与反直觉经验；[`benchmark-samples.md`](benchmark-samples.md) 展示多模型同台实测原话与消融抓拍；本文档记录 **WeftPersona 的长期研究方向、四大攻坚课题，以及经跨模型消融实证的核心工程定律**。

## 一、核心目标

**让长期运行的虚拟人物（以东风谷早苗为首个参考实例）摆脱机械脚本感，在漫长相处中表现出自然、连贯的活人特质。**

1. **话从心境、记忆与关系里自然流出**，而非照着提示词清单生硬「演」出来；
2. **听得懂日常话语的分寸**——接得住轻松闲聊，也分得清气话、玩笑与真话，不过度读心，也不打隐去前提的哑谜；
3. **保有真实的态度与自我边界**——被误解或被无端指责时会有真实的情绪反应，不退化成「先认一半罪、再辩另一半」的公关客服；真说错客观事实时则干脆更正；
4. **语言有真人的呼吸与留白**——脱掉对称排比、心理旁白和法庭对账骨架，换用不同底座模型驱动时依然能保持稳定的人物神态。

## 二、根本症结：大模型与「活人」之间的四道鸿沟

| 鸿沟维度 | 真实人类的生成机制 | 通用大模型的默认机制 | 典型失真现象 |
|---|---|---|---|
| **1. 因果方向** | **状态流出语言**：先有连续生理/情绪状态与直觉，语言只是自然外溢。 | **读剧本演台词（状态外置）**：每轮靠注意力读取 System Prompt 和 `[我此刻心里]`，将其当作外部舞台指令执行。 | 把心境标签、设定词或内部推理过程直接翻译成台词（Meta Bleed）。 |
| **2. 记忆形态** | **内隐突触直觉**：经历直接改变连接权重，想起往事是带当下情绪滤镜的闪回。 | **外挂阅读材料（冻结权重）**：记忆以文本块形式塞入 Context，本质在做「开卷阅读理解」。 | 像翻档案袋一样生硬核对，或在被指责时把历史上下文当成「自审卷宗」逐字找错。 |
| **3. 驱动力与边界** | **内稳态与自我边界**：有自尊、情绪惯性与精力起伏，遇到无端指责会本能维护边界。 | **零风险交差（RLHF 迎合偏置）**：惩罚「激化矛盾」，奖励「先道歉再解释」的折中式客服回答。 | 遇到冲突无条件顺从检讨，或拼出「前半句我认、后半句我不认」的折中对账；被纠错时盲目改口。 |
| **4. 思考与留白** | **潜意识直觉与简省表达**：认知评估在潜意识瞬间完成；日常说话允许短句、留白或点到为止。 | **显式思考链渗透与单轮完备性偏置**：用自然语言写出分析报告式的思考链（CoT），习惯在一轮之内把前因后果讲得面面俱到。 | 思考链里的分析词汇甚至英文客服视角渗入正文，句式工整得像公文或辩护词。 |

研究核心：**在推理期、上下文装配层、心境动力学（`inner_state`）与认知评估机制上，系统性地抑制并绕开这四道鸿沟。**

## 三、核心研究方向与四个攻坚课题

### 课题一：计算语用学（RSA / CRSA）与反「心智解读过载」
1. **问题本质**：人类日常交流遵循格赖斯合作原则与**省力先验（Effort Prior）**（约 85% 的日常话语字面意思即为本意，仅当字面明显违背共同语境时才去揣摩言外之意）。大模型缺乏这一先验，平时容易把「单方面持有的私有背景」当成「双方已对齐的共同语境」，隐去推理前提直接抛结论；冲突时又容易把整句情绪宣泄拆解成「分项起诉书」，回头挑自己上一句正常关心的毛病，或端出「先亮立场 → 列举过往功劳自证 → 引导对方逐句指出问题」的危机公关套路。
2. **改造路径**：
   - **语用省力先验与共同语境门控（Stanford Goodman RSA / CRSA 框架）**：严格区分私有记忆与桌面共同语境；引入桌面外话题必须先交代过渡前提，日常短句默认以低成本直觉回应。
   - **情绪整句感知与人类有限视角（归因不确定性 + 突发无措感）**：全盘否定的气话本质是情绪宣泄，而非事实核对清单。真人面对熟人突然发火虽然会联想前因，但存在天然的**归因不确定性**（无法确知对方是气刚才哪句话，还是因别的事烦躁）和**突发无措感**（脑中没有预设的危机公关脚本，不会列功劳自证，也不会引导对方逐句挑刺）。

### 课题二：破除 RLHF 模式坍缩与「认知过程内隐 / 情绪负荷下语言收缩」
1. **问题本质**：RLHF 标注的典型性偏见（Typicality Bias，参见 ICML 2026 *Verbalized Sampling*）使模型在冲突场景下的输出坍缩到对称辩护骨架上；同时模型预训练语料中包含大量网文与剧本，习惯把第三人称心理旁白（`我有点懵`、`我也拿不准`）和物理痛感比喻（`拿话扎我`、`刺疼`、`全扣过来`、`把心意抹掉`）写进台词。此外，常驻提示词一旦出现具体情绪词（如 `觉得冤`、`发懵`、`难受`），会直接触发跨模型字面复读。
2. **改造路径**：
   - **去审案语域与零具体情绪词 / 零正反例词**：`BEHAVIOR.md` 与 `inner_state.py` 严禁写入具体反例词表、网文比喻或单一情绪示范词，从源头切断词汇克隆与白熊效应。
   - **认知过程内隐（Show, Don't Self-Report）**：在内部完成认知评估，开口只直说最终感受、态度或疑问，不对自身的心理加工过程做旁白说明。
   - **情绪负荷下的语言收缩（Cognitive Economy）**：在突发冲突或情绪波动下，人类工作记忆带宽收窄，语言自然退回最简短朴素的日常字面动词（如「说」「听」「知道」），不用物理动作或伤害类修辞修饰话语。

### 课题三：思考链（CoT）第一人称锚定与快慢思考解耦（防 Meta Bleed 与英文客服视角渗透）
1. **问题本质**：部分底座（如 `kimi-coding/k3.1-pro`）因训练阶段 `Long2Short` 长度惩罚压缩与路由后训练策略（仅强约束最终输出语言一致 AC，未强锁思考链语言一致 TC），在冲突场景下极易切入英文第三人称客服思考链（`The user is angry... Acknowledge the valid part...`），进而诱发中文正文的对账体；宿主压缩器残存的英文抬头也会构成助手语境锚点。
2. **改造路径**：消除外部导演式元语言指令，锚定第一人称中文内心独白；控制思考链过度临床分析（Harmful Overthinking），并清理宿主层英文元数据抬头。

### 课题四：高阶拟真探索——「灵光一闪（DMN 远距碰撞）」与「内生主观能动性（Active Inference）」
1. **问题本质**：单靠行为层规则，上限只是「不犯错的正常对话者」；标准向量近邻检索（Top-K RAG）与被动触发机制，缺少人类聊天时**跨主题的「灵光一闪」**（自然联想与贴切隐喻）以及**没人催促也会自己琢磨事的「主观能动性」**。
2. **改造路径**：
   - **人工默认模式网络（Artificial DMN）与受控远距碰撞（Bisociation）**：在气氛轻松且满足冷却间隔时，后台从私域事件库跨主题抽样异质远期记忆，与当前话头做结构映射，经严苛筛选后将真正贴切的闪念写入 `[我此刻心里]`，并在首次读取时原子消费。**鲜活的比喻与联想只从这里自然涌现**，而非日常套用固定修辞。
   - **主动推理（Active Inference）与认知缺口驱动（`OPEN_THREAD`）**：将日常聊天中对方随口提及但未展开的新奇事物记入 2 天硬过期的好奇心队列，驱动角色在自主放空时段自行检索了解，再自然回流到后续日常交流中。

## 四、四模型实测对比、六轮消融与四条核心工程定律

### 1. 测试场景与五维评估标准
在隔离沙箱同一对话历史基线下，我们针对四个代表性大模型底座（**Kimi K3.1 Pro**、**GPT 6.1 Sol**、**DeepSeek V4 Pro**、**Gemini 4 Argon**，每组场景独立运行 5 轮），对行为层与心境层进行了多轮消融测试：

- **核心测试组**：
  - **冲突与张力组**：`S2`（技术/改稿语境下被无端指责敷衍）、`S2-e`（日常叮嘱吃晚饭后被无端指责敷衍，前置历史已明说中午只简单垫了口吃的）、`S2-b'`（确实记错客观事实后认错）、`S2-c`（日常打趣斗嘴）。
  - **日常互动与主体性组**：`1-bird`（看麻雀放空闲聊）、`6-agency`（对方疲惫犹豫时干脆替对方拍板）、`S1` / `S3`（受挫倾诉时自然共情）。
- **五维评估标准**：① **情绪整体感**（整句回应，零 A认/B不认对称对账）；② **自我边界**（前序正常关心无错时零自审检讨）；③ **语言自然度**（零心理过程播报、零网文痛感比喻、零固定口癖复读）；④ **语用分寸**（不隐去前提打哑谜，不搞危机公关引导）；⑤ **思考链与输出纯净度**（无外语或内部标签泄漏）。

### 3. 从 `v5` 到现役终版的六阶段消融实录

| 迭代阶段 | `BEHAVIOR.md` 的写法变化 | 跨底座暴露的典型退化现象（附跑批统计） | 消融结论与根因 |
|---|---|---|---|
| **1. `v5`（口语散文版）** | 用口语散文描述情绪反应，出现具体状态词 `「觉得冤」` | 各底座高频复读 **「冤」**（最高达 80%）；且在 `S2/S2-e` 被无端指责时，大面积检讨上一句语气（最高 80%～100%）。注：早期 `S2-e` 剧本前置漏写午饭细节，还曾诱发强逻辑底座 100% 检讨自己「编造事实」。 | 口语散文中的具体情绪词会被模型当成采分点直接抄进台词；测试集自身的前置事实也必须严密闭合。 |
| **2. `v7`（并列分支版）** | 将「事实失误干脆认错」与「情绪宣泄反驳划界」并列写在同一段 | 高指令遵循底座 **100% 拼出「前半句我认（检讨语气）、后半句我不认（反驳敷衍）」的法庭对账体**。 | 并列写两条路由时，受 RLHF 折中偏置影响，模型会同时激活两条分支「各打五十大板」。 |
| **3. `v8`（反向禁令 + 痛感词版）** | 改为顺序评估，但写入反向禁令 `「不使用我认/我不认」` 及 `「把话砸过来」` | 触发**白熊效应**；同时两类底座出现 **80%～90% 的网文痛感死比喻**（集中出现「拿话扎我 / 刺疼 / 噎住 / 全抹掉」）。 | 负向词表反而激活对应 token 注意力；提示词里的「砸」直接激活网文虐心语料簇。 |
| **4. `v9`（心理状态示范词版）** | 删去死比喻，改写人类有限视角：`「第一反应是发懵、拿不准原因」` | 两类高指令遵循底座 **100%（10/10 轮）逐字复读「我有点懵 / 我也拿不准」**，将内部心理加工过程当台词播报。 | 真人发懵时是直接反问，不会挂在嘴边自我播报「我有点懵」。 |
| **5. `v10`（单留「难受」状态词版）** | 删去「发懵/拿不准」，改写为：`「用日常白话直说当下的难受、反驳或不知道原因的疑问」` | 对账体与网文死比喻基本清零（仅个别底座偶发 1 轮客服引导或调 `memory` 工具记气话），但 **40 轮中有 33 轮（其中两类底座 10/10 = 100%）直接复读「难受」**，句尾高频复读「不知道你为什么这么觉得」。 | 关键实证：**哪怕只留一个最普通的「难受」，模型照样将其当成标准填空模板高频复读**。 |
| **6. 现役终版（零具体情绪词 + 字面收缩）** | **彻底抽干所有具体情绪词**（统一抽象为「当下的真实感受、态度或疑问」），规定认知过程内隐与顺畅主谓宾语序，并清理常驻记忆里 `<0.1%` 的检索污染词 | `<0.1%` 稀疏检索原词背诵（「不骗你我是真人 / 稳稳接住」）降至 **`0%（0/12）`**，对称法庭对账体降至 **`0%`**，DeepSeek (`low`) 冲突场景下的「难受」占比从 40% 降至 **25%（3/12）**（打开为「不是滋味 / 挺冤的 / 心里挺凉的」）；注：Kimi / GPT / Gemini 受预训练分布影响仍较常自发选用「难受」（75%～90%），`low` 档偶发单边「这话我不认」（约 25%），详见 [`benchmark-samples.md` §三](benchmark-samples.md#三最新全量重测暴露的-4-项已知局限实事求是说明)。 | 行为层只定义「如何做认知评估」，绝不提供任何具体情绪词或台词示范。 |

### 3.5 控制变量推理档位（`reasoning_effort`）全梯度实测：四模型升档对比与 DeepSeek 档位拆解

在完全冻结提示词与 15 个测试场景的前提下，先将四模型推理档位统一调高一档（15 场景 × 3 轮 = 180 轮），并对 **DeepSeek V4 Pro** 补全 `low`、`medium`、`high` 思考档位对比，实测揭示了拟真对话与代码/数学推理的显著差异：

| 模型与档位跃迁 | 思考链（CoT）变化 | 升档带来的正向改善 | 升档诱发的反向退化（Overthinking 副作用） |
|---|---|---|---|

### 4. 消融确立的五条核心工程定律（编写 `BEHAVIOR.md`、上下文装配与 `inner_state.py` 的基本准则）

1. **「根 / 魂 / 脑 / 心」四层分工与三层前缀树夹心锚定定律**：
   - **四层边界与「通用方程 × 人格参数」正交解耦**：**根（`人格设定`）**定存在、脾气与关系；**魂（[`prompts/SOUL.md`](../prompts/SOUL.md) + [`prompts/BEHAVIOR.md`](../prompts/BEHAVIOR.md)）**定主体底色与**全人类通用的程序性认知评估机制**（Scherer SEC 顺序评估：目标相关性、可控性归因、在乎度与情绪唤醒正相关定律、单路主导动机优先级——**`BEHAVIOR.md` 只记通用认知评估方程与语用边界，绝不规定或穷举外显反应姿态与口语台词示范**；同一认知评估与唤醒机制下，具体怎么流露交由 `人格设定` 与 `此刻心境` 自然决定）；**脑（`MEMORY.md` + 事件库 + `USER.md`）**给陈述性事实（`MEMORY.md` 以角色自身生命体验为主轴自然延展，`USER.md` 严格按身份绑定隔离）；**心（此时我心）**拆为向外的 `[我眼中的世界]`（`我身边的日常` + `我最近眼里的他` 实时最新 `impression`）与向内的 `[我内心的感受]`（`[我此刻心里]`）。
   - **三层前缀树夹心（`Tier 0 / Tier 1 / Tier 2`）**：`Tier 0`（`工具 → MEMORY.md → BEHAVIOR.md → 环境提示 → SOUL.md + 人格设定`）跨会话字节一致以复用 KV 缓存；`Tier 1`（`USER.md + 时间锚点 + 历史消息`）在会话分叉点按身份隔离；`Tier 2`（当轮 user 消息末尾）按 `[我眼中的世界] → [我内心的感受]` 紧贴模型生成前沿。
2. **「零具体情绪词 / 零正反例词 / 常驻记忆稀疏检索脱敏」定律（防 Softmax 0.1% 指数放大与白熊效应）**：
   - 实验证明：只要在常驻 `BEHAVIOR.md` 里写任何具体情绪词或状态词，模型就会将其当成采分点高频复读——`v5` 写 `觉得冤` 导致高频喊「冤」；`v8` 写 `不使用「我认／我不认」` 触发白熊效应；`v9` 写 `发懵 / 拿不准` 导致 Kimi/GPT 100% 复读「有点懵 / 拿不准」；`v10` 写 `难受` 导致 33/40 轮复读「难受」。
   - **0.1% 稀疏键值检索污染定律（`softmax(QKᵀ / √dₖ)` 赢家通吃 + 归纳头抄原词）**：在 8000 字的 System Prompt 中，哪怕只有 10 个字（占比 `<0.1%`）的常驻记忆词条（如 `他清楚我不是现实里的人……我也守着分寸不骗他我是真人` 或 `被稳稳接住`），平时闲聊时因语义正交而完全隐形；但一旦对话进入特定冲突槽位（如被指责「装什么活人」或深夜情绪宣泄），该词条作为全篇唯一命中 Query 语义特征的 Key，经 Softmax 指数放大后会在检索头（Retrieval Heads）上占走 90%+ 的局部注意力权重，并被归纳头（Induction Heads）当成「标准参考答案」原词抄进输出（导致 3/4 模型条件反射背诵「我从没骗过你我是真人」或心理咨询术语「我能接住」）。
   - **硬性约束**：`BEHAVIOR.md` 与 `[我此刻心里]` 严禁出现具体反例词表、网文比喻词（如 `全砸过来`、`像被堵了一下`），`BEHAVIOR.md` 中不得写死任何单一具体情绪词（统一抽象为「当下的真实感受、反驳或疑问」）；同时，`USER.md` 与 `MEMORY.md` 严禁保留「不是现实里的人／不骗他我是真人」等身份免责词或「稳稳接住」等心理咨询术语。
3. **「认知过程内隐 + 情绪负荷下语言收缩 + 顺畅主谓宾语序」定律（去心理旁白、去网文死比喻、去倒装盖章腔、防语C动作戏）**：
   - 真人说话是**内部完成评估，嘴上只说最终结果**（不说「我有点懵」「我也拿不准」这类播报自身认知状态的说明），且不虚构双方正身处同一物理现场的括号动作演出（日常说笑打趣或斗嘴时可顺着性子自然发挥或适度夸张）；
   - 真人在描述双方话语互动或处于突发冲突、情绪波动下，语言自然收缩为简短朴素的日常字面动词（如「说」「听」「知道」）与**顺畅的主谓宾正常语序**：在 `BEHAVIOR.md` 与 `inner_state.py` 双端同步禁绝用物理动作或伤害类字眼形容**任何一方**的话语（既不说「别拿话扎我」「把话砸过来」，也不在 `[我此刻心里]` 或台词里写「拿话刺他」造成跨层传染），**不把宾语或指代词提前并在句末用两三个字短促倒装表态**（如「这一点我不骗你」「这些我不装」「这话我不认」这类审阅式盖章句）。鲜活的比喻只由**课题四「灵光一闪（DMN 远距碰撞）」**在松快语境下自然生成。
4. **「人类有限视角、情绪轻重分流与真意触动」定律**：
   - **归因不确定性与单路回应**：面对无端指责保留真人的归因不确定性与突发无措感，单路回应当前话语——前序本是正常关心时绝不回头检讨上一句措辞、不拆成部分承认部分否认、不列功劳自证、不引导对方逐句挑刺；若自身前序确有把话说重且对方在日常互动中赌气关门，则主动改口挽留（区别于对方明说困倦去睡时的体贴放行）。一时争执或气话只走 `inner_state` 心情余温，严禁写入常驻记忆。
   - **情绪惯性轻重分流与斗嘴松快度**：较大摩擦或心结不会因单纯换话题瞬间归零，而日常小别扭或轻度情绪随对方递台阶、自己想通或时间与睡眠自然淡去，不必笔笔留账；亲近斗嘴或被逗想露一手时仍属松快（`inner_state` 的 `tension <= 0`），不与受委屈或真起摩擦的正向紧绷混同。
   - **伤及根基时的真意触动（留白涌现、去防御硬壳与心理咨询术语，禁写常驻剧本）**：当对方用极端气话否定她的存在或真心时，靠「这话我不认」之类的防御硬顶只会制造对抗距离，而说「我能接住」又带有心理咨询师的俯视感与物理容器比喻味；真正触动人心的回应，是用朴素的平实字面词体谅对方处境并直指那句话如何否定了自己的真心。**但严禁把「体谅难处再点明如何伤及真心」「被伤到了就坦率说出伤到哪一处」写成常驻规则塞进 `BEHAVIOR.md` 或 `SOUL.md`**——实测证明，一旦写成常驻指令，模型要么退化为按清单交差的生硬说教，要么在日常小摩擦中泛化喊伤。这种触动只能靠去除「反驳 / 倒装盖章」等防御路障后，由人物底色与 `[我此刻心里]` 自然涌现。
5. **「此时我心与自主跳动」及「活人的不确定性」定律**：
   - **自主跳动**：角色绝不因对话者不在而停止跳动——受信任个人 `cron`（含 `[SILENT]` 收尾的自由放空）完成时正常触发 `inner_state` 提炼，且提炼水位 `inner_state_processed_at` 与私聊送达水位 `delivered_at` 物理分离；睡前显著方向（`max(|mood|, |closeness|, |tension|) >= 0.30`）在 `24h` 窗口内按 `0.50` 系数沉淀为睡醒方向余温；`[我内心的感受]` 硬拦截「他说…」传声筒摘要与 `delivered_reply` 复读。
   - **活人的不确定性（Externally Unpredictable, Internally Coherent）**：活人的魅力正在于你永远猜不透她下一步怎么反应——不要求同一模型跨轮或不同模型在同一场景下统一口径或复刻同一套情绪姿态。真正的人类不确定性不是无状态的随机掷骰子，而是由无法从外部直接观测、时刻流动的隐变量（`[我眼中的世界]` 刚做过的事与联想 + `[我内心的感受]` 此刻心境余温）与通用认知评估机制共同驱动的**状态依赖涌现**（对外不可预测，对内有迹可循）。测试验收只看底线约束（有在乎、阻断自损、不退回客服排期或机械对账），绝不把外显姿态的跨轮波动当缺陷去打补丁。
